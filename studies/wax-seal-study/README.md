# Wax Seal Study

Five single-file interaction studies for sealing a letter with wax: **Fold the Flap → Pour the Wax → Align the Stamp → Press the Stamp → Lift the Stamp**.

See [STUDY.md](STUDY.md) for components, states, transitions and code locations, and `study.json` for a machine-readable manifest.

## Run

No build and no dependencies. Either open `index.html` directly, or serve the folder:

```sh
npx serve .            # or: npm start
# or
python3 -m http.server 8000
```

Then open the launcher (`index.html`) and pick a step. Sound starts after your first interaction; turn your volume up.
